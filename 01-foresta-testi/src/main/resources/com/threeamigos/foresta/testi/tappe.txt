// ---------------------------------------------------------------------------------------------
// Le missioni a tappe (vedi missione_a_tappe.md e TappeRichieste, che legge la riga).
//
// Due radici: TAPPA_MISSIONE dà una missione seria (persona, oggetto leggendario, chiavi, due piste) e
// TAPPA_MISSIONE_FARSA una farsa. Quale chiedere lo decide il gioco (circa una su tre è una farsa: vedi
// CostantiMissioni), perché i pesi [^N] di GrammarBean non sono proporzionali: ogni ramo riceve un aumento in
// base alla ricchezza dei sottoalberi (GrammarBean.md §5.2), e così le proporzioni fra le ricette serie sono solo
// indicative. Le produzioni a esaurimento (NOME_CHIAVE$, CUSTODE_DATI$) si ripristinano dopo ogni riga.
//
// Ogni produzione TAPPA_MISSIONE dà una riga di campi CHIAVE=valore separati da ";", come missioni.txt.
// Una missione è una catena di TAPPE: ogni tappa è un posto di una certa CLASSE (CITTA, LOCANDA, ROVINE,
// TEMPIO, GROTTA, BOSCO, PALUDE, RADURA); la tappa finisce quando il gruppo ci arriva e riceve un'informazione che
// dice dove andare dopo. Campi:
//   TAPPA_n=CLASSE [NEMICO NUMERO]:informazione   dove si va, chi (facoltativo) lo custodisce e che cosa si
//                                  scopre arrivandoci
//   SCENA_n=narrazione/battuta del capo/battuta di un compagno   l'intermezzo dell'arrivo (compagno facoltativo)
//   ARRIVO=CLASSE [NEMICO NUMERO]:testo   l'ultimo posto: dove sta ciò che si cerca (con chi lo custodisce)
//   OGGETTO=LEGGENDARIO           ciò che si cerca è un leggendario (lo pesca la missione); senza, è una persona
//   CHIAVI=n (ricetta delle chiavi: n ricerche in qualunque ordine): CUSTODE_n=CLASSE NEMICO NUMERO CAPO:testo e
//                                  OGGETTO_CHIAVE_n=nome. Se NEMICO è SCAMBIO il custode non combatte: cede la chiave in
//                                  cambio di un oggetto (il CAPO è il nome di una produzione di nomi, come in missioni.txt), e
//                                  SCAMBIO_n=CLASSE NEMICO NUMERO:oggetto/testo dice dove sta
//                                  (in un posto di quella classe, con quella guardia), da portargli
//   BIVIO (ricetta delle due piste): dopo la tappa 1 il gruppo sceglie fra due posti: PISTA_A=CLASSE [NEMICO NUMERO]:testo,
//                                  PISTA_B=..., GIUSTA=A|B (quella che prosegue verso l'ARRIVO) e SCENA_A, SCENA_B. Nella
//                                  falsa pista il testo è un vicolo cieco che rimanda all'altra (%A_ALTRA%): non si fallisce
//   BATTUTA_2, RISPOSTA_2 (farse): un secondo scambio nella scena del mandante; l'ultima RISPOSTA finisce con
//                                  "Cominciate %DA_PROSSIMO%". Le farse hanno 0 o 1 tappa: al massimo due posti
// Segnaposto risolti dalla missione mentre si gioca (la grammatica non conosce i nomi dei posti): %PROSSIMO% il nome
// del posto della tappa dopo, con l'articolo ("le Vestigia dell'Antico Impero", "Malgaard"); le sue forme con la
// preposizione, che la missione scrive giuste: %A_PROSSIMO% (alle Vestigia, a Malgaard), %DI_PROSSIMO%,
// %DA_PROSSIMO%; %MONETE% la paga vera (la base del campo MONETE per il livello del mondo di quando la missione si offre); per il bivio %PISTA_A% e %PISTA_B% (i nomi dei due posti), %A_PISTA_A% e %A_PISTA_B%, e %A_ALTRA% (l'altro
// posto, nel vicolo cieco); %OGGETTO% il leggendario, con l'articolo ("il Bastone dell'Arcimago Smemorato") e %DI_OGGETTO% ("dell'Arcimago…"); %CAPO% il capo di quel custode;
// %POSTO_n% i posti dei custodi. I testi non dipendono da genere e numero di %OGGETTO% (può essere "gli Schinieri"): niente
// pronomi (lo, la, li) né participi riferiti a lui, e si usa %DI_OGGETTO% dove serve "di".
// Nei testi non si usano ";", "/" e [ ] { } | " fuori dalla sintassi; "verso" e "per" non si fondono con l'articolo e si
// possono scrivere davanti a %PROSSIMO%, le altre preposizioni vanno nelle forme dei segnaposto.
// ---------------------------------------------------------------------------------------------
