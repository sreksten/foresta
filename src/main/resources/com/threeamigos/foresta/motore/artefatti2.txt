# Nomi ed effetti degli artefatti generati a caso (vedi GrammaticaArtefatti e GrammarBean.md).
#
# FORMATO DEL RISULTATO
#
# Ogni produzione radice restituisce una sola riga: il nome dell'artefatto, con dentro dei
# marcatori <chiave:valore> che GrammaticaArtefatti toglie dal testo e trasforma in dati:
#
#   <mod:FORZA+1>             un modificatore di attributo (un TipoAttributo) e la sua intensità,
#                             da -3 a +3; il generatore la moltiplica per il gradino del livello
#   <danno:FUOCO>             un incantamento di quel TipoDanno, del grado del livello
#   <soprannome:Diavolina>    il nome proprio; se ce n'è più d'uno vale il primo
#   <descrizione:che brucia>  la descrizione; se ce n'è più d'una vale la prima
#
# Esempio:
#   @la spada ardente<danno:FUOCO><descrizione:che brucia i nemici><soprannome:Barbecue> del Monaco Distratto<mod:SAGGEZZA-1>
# diventa "la spada ardente del Monaco Distratto", detta Barbecue, "che brucia i nemici", con un
# incantamento di fuoco e un malus alla Saggezza.
#
# Ogni marcatore <mod> o <danno> è un effetto e occupa un posto nel limite di effetti
# dell'artefatto (RaritaArtefatto). Per questo il marcatore sta attaccato alla parola che lo
# giustifica, e ogni parte del nome porta UN solo effetto: il numero di parti è il numero di effetti.
#
# PRODUZIONI RADICE
#
# <TIPO>_<n>, dove TIPO è un TipoArtefatto e n il numero di effetti: SPADA_0 ... SPADA_3.
# Il generatore chiede la radice con tanti effetti quanti ne ammette l'artefatto meno uno, lasciando
# un posto libero per la fusione, e ripiega sulla più grande disponibile.
#
# ARTICOLO
#
# "@la " a inizio riga è l'articolo: artefatti2_pp.txt lo elide davanti a vocale, così un
# prefisso può cominciare con qualunque lettera ("l'immane spada", "la terribile spada").
#
# Caratteri da non usare nei testi: [ ] { } | " (sintassi di GrammarBean) e < > @ (marcatori).
